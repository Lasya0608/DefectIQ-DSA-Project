Algorithm & Complexity

A Disjoint Sparse Table precomputes suffix aggregates on the left half and prefix aggregates on the right half of each power-of-two block. For distinct endpoints L and R, the highest differing bit selects a level where the two stored aggregates combine to answer the query in constant time. Singleton queries return the original element.

Preprocessing: O(n log n) · Range minimum/maximum: O(1) · Memory: O(n log n). Uploading new records rebuilds the tables, since DST is a static data structure.

CSV format: date,shift,line,inspected,defects with date formatted as YYYY-MM-DD. Each row represents one production shift or inspection interval.
